/* Program to check given string is palindrome or not

Example-1: For Even number of charcaters

            n o o n \0
            0 1 2 3  4
            
Here we need to swap all the charcaters that are available until i<j.Once condition becomes false, value of i will be greater than the j(i>j).
i>j condition has to be mentioned in the palindrome checking condtion.


Example-2: For Odd number of charcaters
           
           r e f e r \0
           0 1 2 3 4 5

Here we don't need to swap or interchange or check the middle character as there is no more corresponding character for it.
Untill i<j becomes true we need to check, once the condition becomes false, i will be equal to j (i==j). (2==2)
This we have mentioned in the palindrome checking condtion.

*/
#include<stdio.h>
int main()
{
    char x[40];
    int i=0,j=0;
    printf("Enter the string\n");
    scanf("%[^\n]",&x);
    while(x[j]!='\0')
    {
        j++;
    }
    j--;
     while(i<j)                      
    {
        if(x[i]!=x[j])              
        {
            break;
        }
        i++;
        j--;
    }
    printf("i=%d\nj=%d\n",i,j);
    if(i>=j)
    {
        printf("Palindrome");
    }
    else
    {
        printf("Not palindrome");
    }
    return 0;
}
